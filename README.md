# Silent Chat Simulator (Instagram DM UI)

تطبيق فلاتر يحاكي محادثة إنستغرام مع جدولة زمنية لحظية دقيقة (Second-by-Second Replay) وإشعارات مموهة ونظام قفل سري وحماية من لقطات الشاشة.

## الميزات:
1. **واجهة إنستغرام المطابقة:** ثيم داكن، فقاعات متدرجة للمرسل وفقاعات رمادية للمستلم، شريط علوي يحاكي المحادثة النشطة.
2. **محاكاة زمنية حقيقية:** يقرأ ملف المحادثة المصدّر ويقوم بمزامنة عرض كل رسالة بالثانية والدقيقة وفق التوقيت المماثل.
3. **حماية قصوى:** 
   - قفل بكلمة سر (الافتراضي: `0000`) ودعم البصمة.
   - منع لقطات الشاشة وتسجيل الشاشة وإخفاء محتوى التطبيق في الـ Recent Apps عبر `FLAG_SECURE`.
4. **إشعارات مموهة:** إشعار باسم "تحديث النظام" عند وصول رسائل جديدة دون كشف الاسم أو المحتوى نهائياً.

## طريقة الرفع واستخراج ملف الـ APK عبر GitHub:
1. أنشئ مستودعاً جديداً (Private) على حسابك في GitHub.
2. قم بفك ضغط هذا الأرشيف ورفع جميع الملفات والمجلدات إلى المستودع.
3. فور دفع الكود (`git push origin main`)، توجه إلى تبويب **Actions** في المستودع.
4. ستجد Workflow باسم **Build Android APK** يعمل تلقائياً.
5. بعد انتهاء البناء (ظهور علامة الصح الخضراء)، افتح التشغيل وستجد ملف `app-release.apk` جاهزاً للتنزيل والتثبيت مباشرة.
